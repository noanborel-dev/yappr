# PromptShaping

Section 3. Autoplaying demo that loops while in view: the transcript streams word by word, filler strikes through and drops, then the shaped prompt types itself — and as each line lands, the source phrase it came from lights up in the transcript. That highlight is the point: it shows nothing was summarised away.
