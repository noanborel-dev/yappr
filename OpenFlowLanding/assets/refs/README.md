# Reference images

Drop visual references here — images whose *vibe* we want, not necessarily
their subject. Any format (jpg/png/webp/heic), any resolution; these are
never shipped, they're only read to derive direction.

What gets extracted from them:
  • colour temperature and how it sits against the cream palette
  • depth of field / how much is in focus
  • lighting — hard or soft, direction, time of day
  • staged vs. candid
  • camera height and distance

Useful to note alongside a file (just tell me in chat):
  • what specifically you like about it — the light? the mess? the mood?
  • anything you *don't* want carried over

Shipped photography lives in `public/photos/`, not here.
See `components/photos.tsx` for the shot list and spec.
