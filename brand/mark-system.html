The pill's own source comment says it “mirrors the actual indicator pill the user sees in the wild.” It was painted #0E1018 while the notch it depicts is #0A0B0F. Put the logo beside the hardware and the illusion the mark is built on comes apart. Everything else — two whites, two ways of naming one font, three copies that drift — follows from nobody owning the mark.

The system

Two axes and a size scale, not a folder of files. Every useful combination is reachable; nothing is a special case.

01

Lockup — what gets drawn. pill · bare · icon · stacked

02

Tone — what it's drawn on. dark · light · ink · white

03

Size — how big. hero · button · inline · favicon, each step ≈0.62 of the one above, so the dot-to-letter relationship holds as it shrinks.

rgba(255,255,255,.92)

Not #FFF — pure white blooms and fattens the serif's thin strokes.

Rules

Short, because a rule nobody remembers is not a rule.

✕

Don't put the pill lockup inside the notch. The hardware is the pill — you'd be nesting one inside another.

✕

Don't light the dot unless the mic is genuinely open. It is a state, not an ornament.

✕

Don't set the word below 11px. Use the icon lockup instead.

✕

Don't swap the dot to terracotta for brand tidiness. Red-means-recording is worth more than a matching palette.

✕

Don't re-declare the font, the italic or the colours locally. That is precisely how there came to be three.

✓

Do reach for tone="light" over photography, and tone="ink" anywhere a second colour costs money.

✓

Do drop the dot in footers, invoices and legal copy, where it reads as punctuation.

Files

The component is canonical. The SVGs are for everywhere the component cannot go.

◆

YapprMark.tsx — every lockup, tone and size. Import this in the app; Wordmark still resolves to it, so existing call sites keep working.

◆

brand/svg/yappr-icon-*.svg — squircle, circle, light, mono ink, mono white. No text, so these are genuinely portable: nothing to install, nothing to fall back.

△

brand/svg/yappr-pill-*.svg and yappr-wordmark-*.svg carry live <text>, so they need Instrument Serif present. Before sending one outside this repo, outline the text — otherwise it silently renders as Georgia and the mark is quietly wrong.
